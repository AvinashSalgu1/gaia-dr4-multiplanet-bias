# Test data

`GAIA_DR4_PRERELEASE_EPOCH_ASTROMETRY_RAW.xml`: Gaia DR4 pre-release epoch
astrometry for 12 sources (June 2026), unchanged, from
https://www.cosmos.esa.int/web/gaia/dr4-prerelease

Gaia (https://www.cosmos.esa.int/gaia), processed by the Gaia Data Processing
and Analysis Consortium (DPAC, https://www.cosmos.esa.int/web/gaia/dpac/consortium).
